# PlanV5 R09～R11 修复与验收

本记录对应 [R09～R11 复核](./review-2026-09-22-r09-r11.md)。**三项修复已实现并通过数据库回归、完整 P5 a 与 M4 a；两轮进程退出码均为 0，清理核对完成。** 原有 9 个 PVC、27 个工作负载和就绪状态保持不变。真实中文模型评测仍缺实际配置，整体计划不标为完成。

## 实现

- **R09 异常收尾**：动作确认、审批拒绝、执行前失效、执行完成和取消使用 `conversation.ScheduleActionRun`，在改变动作状态的事务内创建 Run 继续任务。只对尚未执行的 pending Agent 任务去重；已经运行的任务不能替代后继通知。已结束 Run 不会被回调复活。原动作 Reconciler 增加待确认/待审批/未派发动作的到期处理，不改动已派发执行。
- **R10 会话归属**：Run 查询、取消和手动压缩统一按企业、Run actor、Conversation owner 及未删除状态校验。变更在事务内再次锁定核验；幂等重放也先检查当前归属和删除状态。内部执行器继续使用内部查询，不为公开 API 保留旧的无 owner 方法。
- **R11 当前文件状态**：预检与模型请求共用 `conversation.ContextFacts`，包含当前 Workspace 身份和生命周期。历史附件引用重新核对其原 Workspace 和文件记录；已删除或属于旧目录的引用不再携带可用路径。模型和压缩指令明确以当前事实为准，文件元数据不能保证当前文件内容存在。Workspace Provider 同步能力快照中的已有目录身份，压缩 v2 记录所用的 Workspace 状态和实际输入 Hash。

实现入口：[动作继续任务](../../internal/conversation/action_continuation.go)、[到期处理](../../internal/action/expiry.go)、[公开 Run 查询](../../internal/conversation/service.go)、[当前 Workspace 与引用投影](../../internal/conversation/context_facts.go)。

## 集群门禁

P5 增加模型接收端的公开 Workspace 事实回显：真实上传 → 删除 → 下一 Run → 同名文件上传到新目录 → 下一 Run，检查收到的身份不同、删除状态有效，并在结束后明确删除新目录。回显不保存或返回 Prompt、文件正文或私有运行配置，只用于确定性 Replay 验证请求接线。

M4 增加 Run 绑定的模型 Preview → 确认 → 独立审批拒绝，及确认后策略失效的实际执行拒绝；检查 Run 终态、无业务变更和下一条消息可执行。另给独立成员普通会话权限，验证读取/压缩/取消他人 Run 均返回 404，删除会话后的原 owner 请求也被拒绝。

两轮均已核实进程退出码、原有 PVC/副本/就绪状态及归属清理，不使用仅业务阶段通过替代完整验收。
