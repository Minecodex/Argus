| D05 | 客户 MCP 只作为文字/结构化数据使用。 | 不接入其 Dashboard、HTML 或 Presentation Extension，不为它配置模板。 |

| D07 | 自有操作提交完全确定性执行；完成后可自动只读验证和总结，再次变更生成新 Preview。 | 已确认的自有操作由其 Action Executor 提交，不转交客户 MCP；不禁止模型在执行完成后分析。 |
| D08 | 保留完整 Workspace 工作目录的最新状态，不承诺每次修改可回滚。 | 当前文件树持久化；不建设逐次文件版本历史。删除、覆盖仍改变当前文件树。 |
| D09 | 每个会话独立 Workspace；关闭页面、结束 Run、闲置、归档均不删除文件。 | Workspace 持久目录与 Sandbox 实例生命周期分离。 |
| D10 | 只有明确删除 Workspace 或永久删除会话才清理；满额停止新增写入，不自动删除旧文件。 | 正常闲置回收只回收计算；清理流程须区分用户删除与实例回收。 |
| D11 | 企业管理员配置企业 MCP 连接、凭据并授权成员，普通用户选择已授权连接。 | 首版无个人连接；平台负责底层环境，不代管客户业务凭据。 |
| D12 | 用户为会话显式选择 MCP 连接并记住选择，所选连接可用工具直接提供模型。 | 新连接不自动加入旧会话；撤权/停用立即阻止后续执行，不能被旧工具快照绕过。 |
| D13 | 镜像预装常用语言和分析库。 | 本期不增加用户上传依赖包的安装流程，缺依赖不能默默联网；具体环境清单随镜像实现与验证。 |
| D14 | 自有 Tool 模板展示业务详情，宿主统一提供影响范围、确认/取消及审批执行状态。 | 用户只确认一次；iframe 不再有确认/取消 Bridge 能力，模板样式不决定最终入口。 |
| D15 | 首期客户 MCP 只支持 Remote Streamable HTTP，stdio 留到后续。 | 不交付 stdio 连接表单/进程/联网 Sandbox；支持 Streamable HTTP 自身 JSON/SSE 响应，旧双端点 HTTP+SSE 不在首期范围。 |
| D16 | 工具容量不足时运行前明确提示，用户减少所选连接或更换模型。 | 不启动本次 Agent 执行，不静默丢弃工具，不自动改用其他模型；保留输入、附件与选择供调整后重试。 |
| D17 | 用户上传业务数据到当前会话 Workspace，模型生成文件在会话提供下载。 | 真实上传与受控产物交付纳入本期，不以文件名或容器路径冒充文件传输。 |

“客户 MCP 自由执行”表示已接入工具不额外套 Argus 自有业务确认流程；不授予跨企业访问、平台凭据读取、任意 Worker 宿主执行或伪造连接配置的能力。

## 2. 设计树

```text
Agent：通用模型循环、原生工具消息、上下文与恢复
├── 自有能力
│   └── 三个元工具 → 自有 MCP Registry / Tool Gateway
│       ├── 查询 → 模型结果 + 可选 Tool 自有模板
│       └── 变更 → Preview详情 + 宿主统一确认/状态 → Commit → 只读验证/总结
├── 客户 MCP
│   └── 直接模型工具 → MCP Adapter → 客户 Server → 文字/结构化结果
│       ├── 企业管理员配置/授权 → 会话显式选择 → 所选连接直接工具
│       └── 首期 Remote Streamable HTTP；超容量运行前提示减少连接/换模型
├── 离线计算
│   └── read/write/edit/bash → 无网络 Sandbox
│       └── 镜像预装常用语言和分析库
└── 每会话持久 Workspace
    ├── 保留完整目录最新状态；不保存逐次修改历史
    ├── 计算实例可以回收，持久目录继续存在
    ├── 明确删除才清理；满额停止新增写，不自动删旧文件
    └── 用户上传业务文件 → 离线分析 → 会话下载模型产物
```

## 3. 实施上必须同步的边界

1. 将“模型总工具数固定三/七个”改为“核心三/七个 + 客户 MCP 的 N 个直接工具”，单独计量外接 Schema Token。
2. 将“所有 MCP 均映射为 category + name 并走自有 Gateway”改为两个来源和执行策略。外接工具身份必须与自有核心工具/隐藏 Commit 隔离。
3. 删除客户 MCP Presentation Extension 的构建、模板校验与浏览器验收任务；保留自有 Tool Template。
4. 将“所有变更都必须 Preview”限定为自有业务变更；离线文件写入和客户 MCP 直接执行使用各自规则。
5. 将“确认后不再启动模型推理”改为“提交不经模型，执行后可只读验证/总结”。
6. 将“Workspace 闲置/过期即丢弃文件”改为“计算实例回收、持久目录保留”。持久化最新文件不等于保留进程内存、连接和全部容器系统盘。
7. 文件目录使用独立持久存储；现有单项 4 MiB Tool Artifact 不作为整个 Workspace 存储。文件交付与受控结果导入需要单独接口。
8. 文档与 E2E 区分普通实例回收、明确删除 Workspace、永久删除会话和本次临时测试资源清理。
9. 增加企业 MCP 管理及成员授权、会话显式连接选择的产品/API/验收路径；配置与会话启用分开，撤权/停用实时拦截调用。
10. 将 iframe Bridge 收敛为展示消息，删除其确认/取消能力；宿主固定控件消费权威动作投影，模板失败不能补造预览或跳过确认。
11. 离线依赖由镜像预装，不把此前推荐但用户未采纳的“上传离线依赖包安装”作为已确认产品功能。业务文件上传与分析产物下载已纳入首期，两者范围分开。
12. stdio/旧 HTTP+SSE 从本期配置、正向执行测试和完成门禁移出；保留 Remote Streamable HTTP 的 JSON/SSE 支持。
13. 运行前服务端检查模型工具/上下文容量；不足时拒绝并给出用户恢复路径，不静默降级工具或模型。
14. 补齐真实文件上传、离线分析、会话下载与跨 Run/实例回收后的持久性验收。
