## A16 最终修复

共享采样优先保留原始首尾、有限值全局极值、有效值与 NaN/正负无穷/null 转换的两侧，再补全窗局部极值与实际样本。重复缩减仍遵守同样约束；预算不足以保留缺测边界时明确省略该曲线，精确统计和完整封存值保留。统计卡片将“最新值不可用”和“整个范围无数据”分开。

独立指标和冻结仪表盘共用该路径。原 8 个复现均恢复正确：峰值 10000 保留，缺测标记不再被删除。[原用例修复结果](../../artifacts/template-v2-r8-sampling-proof/metric-sampling-render.json)。

实际冻结 PromQL 文件保存的是 Matrix/Vector 数组。只读分页现同时接受该数组和对象封装，在原 panel/target 绑定内读取完整 values；跨目标游标拒绝。临时链路逐页读取 **1800 个独立指标样本 + 7202 个冻结仪表盘样本**，合计 9002。模板与 Host 职责未改变，未增加任意 URL、任意工具调用或提交能力。[设计](../05-tool-templates-and-host-ui.md)。

## 浏览器运行方式与失败闭环

完整模板矩阵使用 [playwright.template-matrix.config.ts](../../web/apps/enterprise/playwright.template-matrix.config.ts)：编译后的 mock 门户与正式编译的 Runtime；两项通过拦截 Vite 源模块注入失败响应的主机回调测试使用独立开发服务。它们在同一次完整调用中各执行一次，没有减少原清单、断言或改变既定跳过范围。mock 门户以 NODE_ENV=development 编译，保留原门禁所需的开发组件页；这些产物仅在 artifacts 中，正式镜像仍使用 real 构建。

首轮旧标题精确定位断言已适配新增图表样本摘要；Windows 浏览器 ERR_NO_BUFFER_SPACE 失败轨迹保留，静态资源运行减少开发模块连接开销。初次静态运行未满足两项源模块注入测试的环境要求，使用上述完整矩阵配置后全部重跑通过。

r41/r42 的受控仪表盘公式未考虑毫秒时间窗，改为 floor(vector(time())) 并新增实际引擎回归；r43 图表正确保留 0 位小数，测试误要求小数位，已按冻结定义修正。r44 全链通过后，进一步补齐实际 Matrix 数组分页，再完整执行 r45。新增 92 卡片、17 面板、历史与预览检查的场景总时限为 7 分钟，各卡就绪时限、产品超时和请求预算不变。所有失败记录保留，未自动更新截图基线掩盖问题。

141 个跳过项是需独立环境的其他套件或本版本排除的移动端，没有计为通过；模板真实链路和正式加载独立验收。每个当前绑定都有正式类型有效夹具，临时链路执行选定业务分支，不宣称逐一实际调用全部 106 个绑定。受控 PromQL 公式、告警历史与部分元数据均明确标为测试事实；不作为生产观测。按约定使用确定性回放，**真实模型评测未要求、未执行**。本地 evaluation 的 NetworkPolicy/Egress/共享 Sandbox 限制保留，不宣称生产隔离认证。
