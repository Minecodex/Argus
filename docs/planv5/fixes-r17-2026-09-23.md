## 实现

52 个正式工具已有同包维护的业务元数据：44 个资源、查询和 Preview，6 个遥测工具，2 个文件导入/发布工具。`mcp.Discovery` 保存版本、双语标题和业务描述、关键词、结果语义、前件、意图与参数获取示例。工具的输入 Schema、执行器、权限和模板继续由原所属包负责。

`argus.tool_discovery/v1` 是工具编写者提供的文档契约；`argus.tool_manifest/v1` 是完整 Describe 结果，包含类别、名称、输入 Schema、风险、权限、工具版本及 Discovery Hash。两个 JSON Schema 在 Gateway 启动时真实验证。没有业务文档、空关键词/示例或超过上限的工具不能进入模型目录，不保留从 ID 拼接描述的回退。隐藏 Commit 不暴露文档或执行入口。

关键词归一、排序、去重后计算内容 Hash，文案、前件、结果语义和示例均进入 Manifest Version/CatalogRevision。注册顺序与关键词顺序不影响规范化结果；语义变化则使旧游标和旧 Run 明确失效，不能静默使用新目录。目录复制元数据切片，Search/Describe 缓存返回独立副本。

Search 对名称、业务标题、描述、关键词执行确定性评分。所有空白分隔的查询词必须命中，平分按规范名称排序；英文按词边界匹配，避免 install 命中 uninstall。中文使用维护的词和短语，常用无空格表达在工具自己的词表中定义。这不是任意自然语言分词器，也没有恢复 Agent 的英文候选选择器。

Search 只返回固定上限的摘要，单条摘要最多 256 个 Unicode 字符；完整文档仅在 Describe 返回。500/1000 工具目录的模型核心 Schema 继续为 3 个工具、1296 字节。示例说明业务意图及真实参数的获取方式，不让模型复用虚构资源 ID。

## 本地、契约和数据库验证

- 覆盖 52 个正式工具的完整文档，七类工具的 18 组中英文/同义词检索、AND 多词查询、英文词边界与空查询行为。
- 验证当前权限与缓存隔离、返回值不可修改缓存、名称排序与分页、旧游标失效、文案/关键词/前件/示例/版本变化后的 Catalog 与 Run 恢复拒绝。
- 验证缺失/非法文档拒绝、Search 有界摘要与 Describe 完整说明。
- 原 R17 overlay 对照中的 create/创建、list/列表、delete/删除全部命中，Describe 返回真正业务说明。原失败证据保留；复测只将测试中已删除的旧标题 helper 改为相同的字面期望值，没有放松检索断言。
- 初轮新增测试发现“新增主机”无空格短语未覆盖，已补入主机工具自己的关键词，复测通过；失败日志为 `build/p5-r17-discovery-tests.log`，通过日志为 `build/p5-r17-discovery-tests-fixed.log`。
- 元数据与真实 Input Schema 对照后，监控概览明确使用 `lookback_seconds`，采集器清单明确使用空参数对象，避免示例指导无效参数。

## P5 集群验证
