# PlanV5 使用手册

本手册描述目标产品行为；当前实际验收状态见 [实施记录](./implementation-status.md)。企业门户正式支持桌面 Web，支持中英文和明暗主题。

## 配置和选择 MCP

企业管理员在「MCP 连接」中新增连接，填写名称、Remote Streamable HTTP 的 HTTPS 地址、认证方式及授权成员。首期支持无认证、Bearer、Basic；Basic 分别填写用户名和密码。凭据保存后不回显，编辑时留空保留原凭据。保存、测试、启停和成员授权均在此页面完成。

普通用户在会话的「会话 MCP 连接」中选择已获授权的连接。选择会保留，刷新页面后仍然有效。新增企业连接不会自动加入已有会话。每次运行使用固定工具快照；连接停用、成员撤权或凭据/定义失效会阻止后续调用。下一 Run 会重新获取所选连接的当前工具目录。

外接 MCP 的工具直接由模型调用，结果以文字或结构化数据使用。它们没有平台自有业务工具的 Preview/Commit 和模板流程。stdio、旧双端点 HTTP+SSE、OAuth 自动接入、Skill 编辑器和 Marketplace 不在首期范围内。

## 查询和确认业务操作

可直接描述要查询的主机、Kubernetes、指标、日志、Trace 或 Connector。自有工具结果可带业务详情模板。翻页或调整时间范围时，发送一条新消息，例如「查看下一页」或「把时间改为最近一小时」；旧结果保持原来的数据。

自有业务变更先生成公开预览。宿主显示影响对象、确认/取消和审批执行状态，用户只确认一次。需要审批时进入等待审批，审批通过后由执行器提交冻结的参数。提交结束后，Agent 可以进行已授权的只读验证和总结；再次变更需要新的 Preview。

详情模板加载失败时，确认面板仍可显示权威预览；预览本身缺失、失效或过期时无法确认。确认前以宿主显示的影响范围为准。

## 上传、分析和下载

使用会话输入框旁的上传按钮添加业务文件。上传完成后才会生成真实附件引用；发送消息失败时，输入和已上传附件保留。单文件默认上限为 100 MiB，由平台配置。

例如上传 CSV 后发送：「汇总金额，按部门生成图表，并提供结果文件下载。」已配置离线分析环境时，Agent 可以使用 Python、Node、bash 和预装分析库处理文件。分析环境不能联网，不能在运行期间临时下载依赖；需要的数据应先上传，或通过已授权工具受控导入。

文件位于当前会话独立的 `/workspace`。后续步骤需要的数据应写入文件，不能依赖前一命令的进程内存。模型生成的交付文件由服务器核验并发布，会话中提供下载；模型自行给出的外部 URL 不作为平台文件交付。历史交付绑定明确的内容 Hash，工作区同名文件后来改变不会修改历史下载。

未配置或不可用的离线环境不会阻止自有工具及已授权 MCP 的正常使用，但离线四工具不可用。

## 容量与保留

工具集合或必要上下文超过模型容量时，运行前明确拒绝。输入和附件保留，用户可以减少所选连接或显式更换模型；平台不会静默裁剪工具或自动换模型。

Workspace 默认 2 GiB，企业默认预留池 20 GiB。满额时停止新增写入，不自动删除旧文件；已有文件仍可读取，文件删除仍可释放空间。文件系统自身也会使用一部分容量。

关闭页面、Run 结束、闲置、计算实例回收和归档会话都不会删除工作文件。只有明确「删除 Workspace」或「永久删除会话」才会清理对应工作文件和交付。工作目录保留最新状态，不提供每次修改回滚；确认执行的治理与审计记录不因删除会话而撤销。

首期 Workspace 使用节点本地持久存储，不提供跨节点复制或节点永久损坏后的无损恢复承诺。

## 结果未知

外接 MCP 请求发送后没有取得可信终态时，显示「结果未知」并停止该 Run 自动推进。请求可能已经执行，平台不会自动重发。应先通过业务系统或新的只读查询核实状态，再决定后续操作。
