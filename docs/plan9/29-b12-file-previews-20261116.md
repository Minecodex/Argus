# B12 会话文件统一预览修正

2026-11-16 用户反馈 CSV 没有表格、Markdown 没有渲染。本次覆盖消息附件、Workspace 目录文件和发布交付文件三个入口，共用 `@argus/ui` 的格式判定、内容解码和预览组件。没有改变文件存储、下载 API 或授权边界。

## 原因与处理

- CSV 原来直接进入文本预览，没有分隔文件解析器。
- Markdown 原来只看显示名称的后缀。交付文件可以使用不带 `.md` 的自定义标题，实际 `text/markdown` 类型未被使用。
- JSON 原来的解析再序列化会改变超过 JavaScript 安全整数范围的数值。现在只校验语法，按原始词法格式化，不把原始整数变成浮点数。
- 预览格式优先使用明确 MIME；普通文本类型可结合后缀，缺后缀的显示标题可结合真实路径。明确的二进制类型不能因为改名而变成文本预览。

## 格式矩阵

| 格式 | 预览行为 |
| --- | --- |
| CSV / TSV | 共享表格；默认首行表头，可切换无表头；支持 BOM、CRLF、字段内换行、分隔符和双引号转义 |
| Markdown | 标题、段落、列表、GFM 表格和代码块；原文可切换；沿用不执行原始 HTML、不加载远程图片的共享渲染器 |
| JSON / JSONL / NDJSON | 缩进展示，保留大整数、指数和字符串原始值；格式错误显示说明和原文 |
| YAML / TOML / XML / SQL / 常见代码 / HTML / SVG | 只读源码，可复制；不执行脚本、不注入 HTML/SVG |
| TXT / LOG / 其他文本 | 保留换行的纯文本 |
| PNG / JPEG / GIF / WebP / AVIF / BMP / ICO | 验证位图签名后使用受控 Blob URL 展示，关闭后释放；解码失败明确提示 |
| PDF / Office / 压缩包 / 其他二进制 | 明确提示下载查看；不引入 iframe、第三方在线转换或向外部传输文件 |

## 预算与错误

继续通过原有鉴权接口读取，单次预览最多 2 MiB，超限提示下载。关闭取消未完成请求；重新打开重新校验访问，不复用长期内容缓存。权限拒绝或来源授权失效时显示错误。

表格最多渲染200条数据、50列，每个单元格最多4096字符，超过时明确提示，可以切换原文或下载完整内容。JSONL 最多展示200条记录；JSON 嵌套最多64层，超限回到原文；Markdown 超过200,000字符以原文显示，避免复杂渲染阻塞页面。截断只是浏览器展示预算，不改文件或下载字节。

文本默认严格 UTF-8，支持 UTF-8/UTF-16 BOM 和明确 charset。不猜测未知传统编码，不能解码或含二进制空字符时提示下载，不悄悄替换成乱码。

所有预览使用中英文本、共享间距及明暗 design tokens。CSV 公式和 HTML 标签按普通单元格文字展示。
