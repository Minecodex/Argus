## 历史与权限边界

历史 Tool 模板继续使用当次 Hash，结果事实与数据库记录不回写。新的 Tool 模板及资源元数据在后续调用使用；历史会话统一获得 Markdown、事件排序、工具步骤、文件预览及资源名称，但旧 iframe 仍为其原始展示版本。模板业务选择仍在后端 Tool 包，门户不维护第二套业务结果渲染器。

告警/指标的 Presentation Builder 在读取资源名称前复核当前资源权限。资源和文件预览不会使创建者、旧查询或缓存获得额外访问权。模型内容不会执行 HTML，模板 Bridge、PendingAction 和隐藏 Commit 边界保持原有契约。
