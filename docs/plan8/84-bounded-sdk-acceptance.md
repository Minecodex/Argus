# SDK 原生验收分组与总时限

R57 的 SDK 检查在同一个 Go 测试进程中串行执行 12 个协议、容量和故障场景。五分钟重试缺口场景实际通过，但整组达到 Go 默认十分钟总时限，后续用例未完成。该结果是验收驱动失败，不能解释为资源无法验收，也不能将已经运行的少数用例当作整组通过。

将此项拆为六个职责明确的检查组：协议与实际浏览器、容量、队列与磁盘故障、五分钟缺口、TLS 与配额、交付控制。每个原具名测试恰好执行一次，未归类的新用例直接拒绝，不静默遗漏。保留协议组 `sdk` 身份与既有产物位置。

全部容量阈值、单批数据最多重试五分钟、每项检查总预算和真实模型调用预算不变。各组在已有预算内独立执行，避免多个长场景叠加触发进程级默认总超时。环境与参数各自复制，分组不能污染相邻检查。

全量检查组数相应从 79 增为 84；原组失败和清理记录保留。正式代码合入后重新冻结源码，并以新版本执行组件、补充具名观察、完整平台、门户与最终矩阵。旧版本的成功、失败和未运行结果均不直接改写成新版通过。
