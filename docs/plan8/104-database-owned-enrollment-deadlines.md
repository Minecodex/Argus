# 遥测接入凭证的数据库时间权威

2026-10-25。R83 原生数据库角色检查实际触发了十分钟期限约束：应用计算失效时间，数据库生成创建时间，两个时钟在边界处导致合法签发被拒绝。另在真实隔离 Schema 中复现了普通签发期限跨时钟、长事务默认时间、修复入口返回期限与存储不一致，以及事务开始后的实际过期消费。

修正覆盖普通 Collector 接入和 PKI 修复共用的查询。调用方只传有效秒数；创建和失效时间由同一数据库 statement_timestamp 计算，允许 1～600 秒，原数据库十分钟上限约束不变。修复入口返回实际持久化期限。读取时在数据库排除过期或已消费记录，仍核对 Collector 归属；消费使用当前语句时间，避免 now() 固定为事务起点。签发失败、过期或重复使用均失败关闭，证书和凭证写入事务保持原子回滚。

Schema 仍为 49，没有修改历史记录、放宽期限或增加权限。OpenAPI、SDK 协议、前端、Collector 插件、制品与默认查询保持原边界；使用规范 sqlc 生成和分文件步骤更新内部参数。额外静默 Gateway 诊断候选没有合入。

回归使用本轮测试库的独立 Schema，不改变宿主或数据库时钟，不修改实际公共表约束。普通期限与修复入口的修正前失败、完整候选通过及输入摘要分别保留。五个具名根测试纳入已有 runtime-database-roles 强制分组，完整注册仍为 90 组；新源码单独冻结并重新验收，旧失败不改写。
