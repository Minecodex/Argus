## 行为边界

- 自有工具分类仍只有一份中英导航，由 Agent 指令与工具 Schema 共用。`metric/query` 用于实际指标值和时序；`metric/overview` 明确为覆盖、来源、记录／点数统计，不能替代数值查询或证明资源健康。
- 指标名未知时，可以在明确授权资源与请求时间窗中使用已有查询能力的非空名称选择器 `{__name__=~".+"}`，保留系列、样本、扫描及结果预算，读取实际名称与数值，再按需定向查询。不编造指标名，也不扩大资源范围。
- 结束分析前核对用户要求的每个资源和信号，须有实际查询结果或明确失败／不可用证据。部分取数保持部分结论，不把覆盖统计视为完成全部分析。
- 用户要求有效 JSON 时，标识和枚举原样保留，字符串中的引号、反斜杠与控制字符必须转义。优先在已有授权的离线 Workspace 分析中使用标准 JSON 库序列化和解析，再返回验证后的内容；不因此增加远程执行或未授权操作。

这项改进只改变公共取数说明与共同推理指导；不修改原业务断言、严格 JSON 解析、权限、查询预算或 24 轮推理上限。
