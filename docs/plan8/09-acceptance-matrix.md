## 每个集成的附加门禁

[集成清单](./07-integration-catalog.md)全部 39 个 P8-Ixx 必须有选型审查结论；每个纳入支持的版本/拓扑组合都需要以下五项，记录实际目标版本、Collector/模板版本和证据：

| 后缀 | 内容 | 通过要求 |
| --- | --- | --- |
| CONFIG | 新建、认证、可达性、能力 Schema | 从实际执行 Collector 检测；缺组件/权限/TLS 错误有准确状态 |
| DATA | 真实采集与三信号链路中的适用信号 | 实际目标产生数据，可信归属经 Kafka/存储/查询保持一致 |
| VIEW | 默认图表与过滤/下钻 | 实际指标与期望值/单位/标签/聚合对齐，模板依赖齐备 |
| AUTH | 企业/目标/应用/凭据/查询授权 | 负向和撤权行为正确，不能因关联或相同 Collector 扩权 |
| LIFECYCLE | 启停、修改、重启、迁移/删除 | 只影响目标采集，历史/状态/凭据与其他实例正确 |

候选审查和实际支持组合的五类门禁分别计数；组合数量可能大于或小于 39，不再固定声称 195 项必过。报告展开具名的集成/版本/拓扑/门禁，无合格内置组件者保留暂缓缺项及证据。主机及 K8s 12 个内置能力仍各执行五类门禁，不以目录存在代替验证。
