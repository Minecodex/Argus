# Helm 仓库与 OCI Chart 接入

2026-10-20，接续 [54 审计](./54-completion-audit.md)，实施中。

补齐原计划的仓库和 OCI 来源。下载在集群当前 Direct/Connector 执行路径的预览阶段完成；复用已有短期加密输入，来源认证不进入命令持久内容、模型、预览、审计或凭据目录。下载结果核验 Chart 名称、精确版本和摘要，固定到现有加密渲染计划；确认、执行、重试及恢复均不重新下载。

复用 Helm/ORAS 原生格式与协议库，不调用外部 Helm/容器 CLI，不读取执行端 Docker/Helm 登录缓存。来源网络复用已有目标地址校验，逐请求校验及连接固定地址；禁止元数据/回环目标，禁止环境代理、跨域凭据转发和 TLS 降级。支持自定义 CA；非 TLS 源须显式选择，默认严格验证 TLS。OCI 跨域认证服务需显式声明信任地址。

来源获取与隔离渲染分开：渲染子进程仍不访问网络或系统凭据。原有逐对象 dry-run、UID/版本、Namespace 和权限检查保持；Repo/OCI 不能扩大 K8s 权限。新来源契约使用 Helm v2 能力协商，旧执行端明确拒绝；不建设长期双轨。

验收覆盖仓库与真实 OCI Registry、认证失败/恢复、摘要/版本不符、重定向/DNS/预算边界、冻结后来源变化或停机、Direct/Connector 契约、领域/HTTP、门户中英明暗及实际 K8s 生命周期。阶段结果单列，Plan8 整体与发布状态不因本轮组件验证自动通过。

## 实现

- 门户使用已有共享表单、Select、受保护输入和审批组件，提供上传、仓库和 OCI 三种来源。普通操作只需地址、Chart 名称（仓库）及精确版本；摘要、认证、CA、明文 HTTP 和跨域认证服务在可展开设置中。预览显示来源、传输方式、版本及实际摘要。
- 仓库采用 Helm 的原生 index 数据模型，读取精确版本、验证声明摘要和实际 Chart 元数据。OCI 采用 ORAS 原生客户端及 Helm 媒体类型，验证 Manifest、配置和 Chart 层的大小/摘要/名称/版本；不拉取容器镜像或外部层 URL。
- TLS 默认验证系统根，可附加 CA，不能跳过校验。Basic 或 Bearer 认证二选一。仓库跨域包/重定向不携带认证；OCI 跨域 token 服务只有显式声明的精确认证地址可以接收源凭据。目标地址复验、连接 IP 固定、禁用代理、最多三次重定向及拒绝 HTTPS 降级共同生效。
- 下载后的 Chart 以独立 AAD 加密返回控制面，连同来源凭据绑定在相同短期输入机制。控制面核验原始包和加密渲染计划，再原子替换为固定 Chart/values/Key，清除仓库认证字段；确认和恢复不再次访问来源。执行还验证原始 Chart/values 的键控摘要，防止渲染与 Helm 历史脱离。
- 不新增常驻服务、登录缓存、独立凭据目录或外部 CLI。渲染子进程不接收源认证。原有 Direct/Connector、逐写授权、Namespace UID/资源版本、审计和错误脱敏复用同一领域服务；v1 执行端不能接收 v2 任务。

来源仍按预算工作：单 Chart 384 KiB、values 96 KiB、展开 8 MiB、100 个对象；仓库 index 2 MiB、单 OCI Manifest 128 KiB、配置 96 KiB、最多三个层描述；下载会话共 4 MiB/32 次请求/20 秒，同一执行进程最多两个来源解析并发。组合输入/密封计划继续受现有消息上限限制。缺失依赖不隐式联网安装，外部 Schema 和可执行插件仍禁止。

## 证据及完成边界

本轮冻结记录和工程结果分别写入 `artifacts/plan8-helm-sources-delivery-manifest.json` 与 `artifacts/plan8-helm-sources-final-checks.json`，只描述本轮实际执行范围。

真实源使用独立 TLS/Basic 仓库和官方 Distribution Registry 3.0.0，由 ORAS 发布真正的 Helm OCI 制品。原生测试先完成仓库/OCI 两个 dry-run，再关闭全部源，随后实际创建 ConfigMap 并核对冻结随机值；审批前后修改 protected values 被拒绝。数据库链路另验证来源认证从临时输入移除、来源离线后确认/Worker/逐写许可和实际对象仍成功。接入路由/身份由明确夹具提供，不冒充已部署 Connector 或正式注册。

HTTP 验证源凭据确实经私有输入传递、认证失败返回安全错误且不留 staging；旧上传、命名空间、幂等、取消/撤权和原生生命周期继续回归。门户仅用 mock 验证中英明暗和私有内容不落 localStorage，mock 摘要明确标注未验证，不伪造真实制品摘要。

失败迭代保留：数据库原生测试最初未接入本测试程序的隔离渲染入口，已使测试入口与真实 server/worker/Connector 一致，没有放宽渲染预算。门户测试修正成功后重开目录及英文按钮名称的断言。契约文案触发既有旧词检查，已调整来源描述并重新生成，没有降低检查规则。

本轮只补齐仓库/OCI 这个实现缺口，不把完整 A72、T11 或 Plan8 标为通过。其他真实 Chart/拓扑、生产网络、正式 Connector/Gateway/Ingress/门户、完整异常组合和发布仍需验收；Windows 主机实测继续暂缓，其他已确认暂缓项保持不变。
