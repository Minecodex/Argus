# PlanV2 交互原型

入口：[../demo.html](../demo.html)。仅供提前核对产品意图，不连接真实服务。

Q35/Q36 的交互已补入“多来源与两层过滤”示例：SkyWalking、Jaeger、Prometheus、Filelog 分别绑定，提供顶部通用条件、来源专用局部条件及默认值草稿发布。使用模拟数据展示，尚不代表厂商后端、真实来源识别或完整 APM 已实现，规则见 [专项设计](../04-collector-plugins-and-source-views.md)。

## 如何查看

推荐从仓库根目录启动：

~~~powershell
python -m http.server 8875 --bind 127.0.0.1
~~~

浏览器打开 http://127.0.0.1:8875/docs/planv2/demo.html。丰富图表复用仓库 node_modules 中锁定的 ECharts 6.1.0；依赖缺失时先按仓库常规方式安装 pnpm 依赖，不从第三方 CDN 运行脚本。

默认“本轮变化点”列出二十个前后对照，可跳转体验、勾选核对、记录本地备注。13～15 为来源和两层过滤；16～20 为配置/发布修复、APM/标准下钻、最新版本 Chat、来源历史及归档恢复。最新场景直达 http://127.0.0.1:8875/docs/planv2/demo.html#apm，原两层过滤场景为 #sources。支持中英文、深浅色、编辑者/只读身份；不清空既有草稿或核对备注。

## 可直接核对的流程

| 变化 | 体验方式 |
| --- | --- |
| 草稿与发布分开 | 编辑名称、统计图或变量，保存后查看发布版；刷新后从“我的草稿”恢复；最后统一预览发布 |
| 自动回退全部 | 点击变化 02，初始选中 staging；切到最近 15 分钟，选值自动变为全部，系统资源范围不变 |
| 变量构建器 | 在草稿内选择信号、字段、前置变量和默认值，查看候选及引用关系；没有变量 DSL 编辑框 |
| 三信号编辑 | Metrics、Logs、Traces 都有构建器；转成语句后修改为无法无损还原的表达式，保留 DSL 并解释原因 |
| 发布状态 | 草稿中展开“演示场景”选择无数据/服务不可用；结构检查通过可带样本警告发布；预览中可模拟其他人发布并整理冲突 |
| 资源入口 | Host/Cluster 页面管理关联，快捷打开预选该资源，随后可切换其他已授权资源 |
| 对象权限 | 只读身份能看已授权 Dashboard 的查询定义；不能编辑，看不到 host-pay-02 或未授权的订单仪表盘 |
| Chat 分析 | 未指定目标时先列授权候选；查询工具内部模拟生成文件，再展示 read/grep/bash 分析过程与结论；可展开查看样例文件 |
| 连续追问 | 明确主机、环境和时间后再问“那昨天呢”，继承仪表盘、资源与变量；取数情境独立于 Dashboard 页 |
| AI 创建 | Chat 使用 /创建仪表盘，可生成 Builder 或 DSL 草稿，再复用同一发布流程 |
| 来源独立 | 点击变化 13，对比 SkyWalking 的实例/接口、Jaeger 的操作/标签；打开链路可见来源相关详情 |
| 两层过滤 | 点击变化 14，顶部选 host-pay-01；只改 SkyWalking 服务，其他三张图内容不变；切 15 分钟时 payment-canary 自动回退全部 |
| 局部高级条件 | “更多筛选”提供来源对应字段、请求状态、关键词和时延；手输条件点击应用或回车，无结果仍保留条件 |
| 默认值发布 | 点击变化 15，局部筛选后存为草稿默认值，或在统计图配置中改来源/默认条件；查看发布版不提前变化，刷新后恢复草稿，预览明确列出来源和默认值差异 |
| 配置与发布修复 | 变化 16：来源切换使旧无损转换失效；DSL 未定义变量阻止发布；查询、变量默认值、布局和自动刷新展示实际差异；日志统计/趋势/表格真正切换 |
| APM 与标准下钻 | 变化 17：服务总览、拓扑、接口、单 Trace 详情；点击实体展开/全屏，在编辑器“标准下钻”中生成、停用或修改定义，随 Panel 发布 |
| 最新版本与独立默认条件 | 变化 18：在 Chat 选择支付仪表盘（默认 1h）和 APM 示例（默认 15m）；分析后到 APM 页“模拟发布下一版本”，追问时采用最新版本，旧分析仍标原版本 |
| UI/AI 共用下钻 | Chat 已选择 APM 示例后，输入“SkyWalking trace-01 关联日志”；模拟工具通过同一已发布下钻定义交付明细文件，停用该定义后不能绕过 |
| 来源历史 | 变化 19，展开“来源生命周期（模拟）”：停采后仍能查历史；重装后的 g2 实例与旧代次分开；“恢复来源演示状态”仅清除该模拟开关 |
| 归档恢复 | 变化 20：非空分组归档被拒绝，可先迁出；Dashboard 归档保留个人草稿，恢复后提示重新核对基线；所有生效操作展示预览 |

仪表盘页面没有导出按钮、导出来源配置或 AI 分析区。文件交付仅在 Chat 的模拟工具过程中出现。

## 演示边界

- 数据、样本检查、取数、文件交付、AI 判断均为模拟；不调用真实查询引擎、模型、Workspace 或 Kubernetes。
- 本原型在当前浏览器保存个人草稿、发布版本、关联、Chat 历史和核对备注；正式实现仍按计划使用服务端持久化。
- 原型只对自身构建器生成且未被改变的语句提供保守、无损的反向切换；手写语句保持 DSL。结构检查不是 PromQL/KQL/GraphQL Parser。
- 部分趋势/统计展示使用预设数据；DSL 不会在浏览器执行。AI 结论用于展示流程，不能当作真实诊断。
- 备注只保存在本地，不发送反馈。演示对象权限不构成生产安全边界。
- 复用仓库 design-tokens；静态原型的样式和页面拼装只位于本目录，不作为业务应用的平行组件库。正式开发继续使用 @argus/ui。
- Demo 不构成正式接口、后端或验收证据。正式产品的非模型范围已在后续实施中完成，当前状态、真实模型暂缓项和部署边界见 [2026-09-28 验收结论](../completion-review-20260928.md)。

## 文件职责

- ../demo.html：页面入口与本地资源加载。
- styles.css：使用共享 design token 的桌面原型样式。
- i18n.js：中英文文案及变化说明。
- model.js：模拟对象授权、数据、草稿状态机、参数与查询模式。
- views.js：原型页面和弹框。
- app.js：页面交互、模拟 Chat 流程及本地存储协调。
- source-data.js：来源注册、独立样例记录、局部参数与候选范围、来源示例的非破坏性初始化。
- source-views.js / source-filters.css：来源视图、两层筛选、局部更新、默认值配置及变化 13～15。
- workflow.js：逐 Dashboard 的 Chat 上下文、最新版本/兼容性、明细文件模拟、完整发布 Diff 和生命周期校验。
- apm.js：APM 样本汇总与拓扑、Trace 详情、标准下钻契约和受限模拟执行；人工/Chat 复用 resolver。
- features.js / features.css：变化 16～20、来源生命周期模拟、归档恢复及全屏入口。
- tests/review-model.test.cjs：可重复执行的原型回归测试，运行 node docs/planv2/demo/tests/review-model.test.cjs。

所有单个前端文件低于 2000 行。正式实现不得将模拟查询、客户端权限或浏览器持久化当作生产实现。

## 本轮展示增强

新增变化 09～12 与“三信号观测工作台”：11 类 Metrics 展示、日志结果内探索、Span 瀑布与自由网格。编辑态拖标题左侧把手移动、右下角改宽高，方向键也可操作；布局以 x/y/w/h 保存到个人草稿，碰撞面板下移。Q27～Q31 明确保留 KQL、OTLP/ClickHouse，目标覆盖完整 APM，详见 [能力讨论](../03-observability-depth-discussion.md)。原型不证明完整跨批次 Trace、真实授权展开或 APM 分析后端已实现。

新增文件：layout.js（网格状态和交互）、visualizations.js（ECharts 与日志/Trace 探索）、exploration.css（相关样式）。日志搜索、标签和上下文均限本次模拟结果，Span 树为样例，不能当作全量查询或真实链路完整性证据。

新来源示例中的局部条件在模拟查询分页/limit 之前应用，受顶部时间/资源及实际引用的共享变量约束；候选失效回退仅针对候选型字段。来源记录由明确的 fixture 生成，不能代替正式 Collector 来源标记。局部更新只重新渲染本图，草稿和核对备注沿用原存储键，不清空既有用户数据。Chat 创建独立上下文，只使用已发布默认值，不复用页面临时条件。

前一轮基础验证：16 项模型检查通过，覆盖来源分开、全局/局部条件、失效回退、无数据保留手输条件、只读资源范围、先过滤后 limit、草稿/发布默认值和日志关联标识。浏览器检查覆盖局部更新不改变其他图、来源切换、草稿刷新恢复、可读发布差异、展开视图、只读模式、中英文及深浅色；未出现浏览器控制台错误。以上均为静态原型验证，不是正式产品或 Kubernetes E2E 验收。

后续整体审查发现的六项组合缺陷已在本轮 Demo 修复，复现记录和修复范围见 [审查报告](../05-closure-and-implementation-review.md)。新增的 24 项可重复回归覆盖这些缺陷、跨版本继承、动态来源/历史、标准下钻、聚合与明细分离、归档基线及时间桶边界；不能据此宣称正式后端或 Kubernetes 验收通过。

APM 的调用量、错误率、P95 与拓扑来自模拟样本，均明确标注覆盖范围；Q34 的正式采样统计口径未据此定案。标准下钻文本作为配置样例，任意手写 DSL 仍不会在浏览器执行。旧 Demo 没有明细定义的固定跳转保留兼容演示；编辑并保存后会形成显式下钻配置。完整 Collector 身份、厂商适配、查询执行、导出和真实 Workspace 均待正式实现。
