# 变量与局部筛选执行契约

本页记录正式后端已实现的参数语义；页面交互与 Chat 接入仍按实施状态单独验收。

## 配置与引用

- 全局变量使用 `CandidateQuery`，按 `filters[].variable` 建立依赖；局部候选还可通过 `local_parameter` 引用同图内的前置条件。循环、未知引用及多选绑定标量条件在配置校验时拒绝。
- 局部条件分为 `query`、`text`、`number`。查询候选允许自动回退 All；手输文本与数值不因无数据清空。必填手输参数可声明 `required`，不能传 All。
- Builder 过滤值只有一个来源：静态 `value` / `values`、全局变量或局部参数。跨来源类型或跨信号使用共享变量时，通过 `parameter_bindings` 明确 `identity_mapping` 或 `value_map`；缺少选值映射时报错。
- PromQL 参数只绑定标签匹配值，KQL 参数只绑定条件值，写作完整的 `$name` / `${name}`。不进行字符串替换；PromQL 原生替换函数中的捕获组引用不受影响。GraphQL 使用声明变量及其原生类型。
- All 移除该参数对应的业务条件，资源授权、来源集合、时间及其他条件仍生效。KQL 的 OR / NOT 内无法明确移除条件时拒绝发布；需要自动 All 的参数不能绑定必填 GraphQL 变量或不支持集合的标量位置。
- 编译参数化定义时只返回校验结果、结果类型和定义哈希；验证用的临时值不会作为可执行查询返回。正式执行从冻结的有效选值重新绑定和编译。

## 执行与候选

`ExecutionInput.variables` 按变量名传值，`local_values` 按 Panel ID、局部参数 ID 传值。`panel_ids` 限定本次刷新的统计图；局部候选只刷新所选图。全局变量不隐式作用于未引用它的展示或候选查询。

执行冻结已发布版本、绝对时间、授权资源和全部候选/展示查询的来源集合，随后依依赖顺序发现候选。返回有效 `variables`、`local_values`，以及候选状态、`selected_exists`、是否发生 `reset` 和来源快照。运行时改变选值不写回草稿或已发布默认值。

只有未筛选且完整的候选集合，或精确成员检查证明当前任意选值消失，才把整个单选/多选回退 All。搜索、后续分页、截断和查询失败不能作为选值不存在的证据；失败时保留选值和明确的验证状态。下游查询使用已经完成回退的上游有效条件。

Catalog 使用排序键游标分页。游标与时间、来源、资源、查询条件和授权版本绑定；上下文变化必须重新开始。`has_more` / `next_cursor` 描述分页；`complete` 表示本次返回是否包含未搜索的完整候选集。每页都可独立验证 `selected_values`，验证不受搜索或分页游标影响。

目录、候选、指标类型验证与展示查询共享扫描、行数、结果体积和执行时间预算；失败请求扣除预留额度。候选列表与成员检查也共享同一扫描额度，避免分两次查询突破预算。类型、参数与预算错误阻止发布，临时数据服务不可用保留为样本未验证状态。

## 当前证据

自动化已覆盖语言结构绑定、特殊字符、多选类型、跨来源映射、依赖与回退、局部刷新、取消和预算。独立临时 Kubernetes 中的 PostgreSQL / ClickHouse 已覆盖参数化草稿确认发布、真实数据执行、发布默认值保持、候选分页与精确检查。正式页面的搜索/失败保留、确认消失后 All 回退，以及本轮新增三页候选/级联/局部条件/跨信号映射已有验证，详见 [交互收尾记录](./interaction-boundaries-20260927.md)；跨厂商和 Chat 对应全链路仍单独验收。

页面局部候选使用本次执行解析出的资源并按 Panel 适用类型过滤；结果为空时不调用 Catalog，避免把空数组解释为全部授权资源。候选不可用/预算不足的状态参与查看页完整性汇总并显示警告，不能被一次成功的局部图刷新覆盖。正常候选分页不算查询失败。弹窗打开期间收到新的有效选值时同步选择，执行协调未完成时禁止应用。
