# 资源关联入口位置交互提案

日期：2026-10-07。状态：推荐方案已获用户确认并完成正式组件重构，本地正式 r7 已交付；实现与验收见[正式记录](../../plans/frontend-redesign/resource-links-20261007.md)。以下保留原型说明与原型证据，不作为正式产品验收。

[打开示例 demo.html](./demo.html)。原型沿用 Argus design token，支持中文/英文、浅色/深色以及桌面尺寸。HTML/CSS/JS 分文件，每个文件小于 2,000 行；仅操作本地示例状态，不访问业务 API。主题/语言使用独立 localStorage key `argus.planv2.resource-links-ux.v1`。

## 为什么调整

当前 `DashboardBindingSummary` 是资源绑定的反向清单，并不是配置资源查询范围的入口。它即使无关联也占据整行，位于查询条件与图表之间，使主线操作中断；用户还容易把它理解成另一层资源过滤。

推荐方案：普通仪表盘主区直接从查询工具栏进入统计图；反向关联放入右上角“更多 → 关联资源”，点击后以只读抽屉查看及打开资源。管理关联仍在主机/Kubernetes 详情，示例用“仪表盘”页签组织。经资源快捷入口打开时，在标题的版本信息旁展示“来自资源”的小链接，顶部资源筛选预选该对象；用户切换筛选后，当前范围以筛选器为准，来源提示只记录导航路径。

备选方案：如果从仪表盘反查资源是高频任务，可把“关联资源”作为标题旁的小按钮，点击同一抽屉。原型底部可切换两种位置。两者均移除图表上方的通栏折叠区。

Grafana 允许将导航链接放在仪表盘顶部，也可收进 controls menu；本提案借鉴其低频导航的收纳方式，资源绑定的语义仍由 Argus 定义。[Grafana Manage dashboard links](https://grafana.com/docs/grafana/latest/visualizations/dashboards/build-dashboards/manage-dashboard-links/)

## 可点击路径

1. 仪表盘：右上“更多 → 关联资源”查看主机/集群，点击“打开资源”。
2. 资源详情：进入“仪表盘”页签，打开关联仪表盘，观察标题来源与资源筛选的预选；切换“全部授权资源”后，来源提示仍保留。
3. 资源管理：点击“管理关联”，逐项关联/解除，先预览再确认；取消不修改关联，解除也不删除仪表盘或改变查询与权限。沿用现有单绑定预览接口，不暗示已有批量事务。
4. 底部可切换入口位置、只读用户、无关联、加载失败、重置；失败用重试恢复，未知计数显示“—”，不当作 0。
5. 只读用户仍可查看关联和导航，管理操作按资源管理权限隐藏；这里的角色是原型模拟，不能替代实际服务端授权。

## 正式实现边界

- 保留现有 `DashboardBinding`、Host/Cluster 对象授权及 PendingAction。仪表盘菜单只提供只读反查与导航，不新增仪表盘侧绑定写入权限。
- 绑定不进入 Spec，不授予权限、不限制查询全集，也不触发新 Revision。仪表盘可以无绑定、由多个资源关联。
- 候选与反向列表仍同时检查资源和仪表盘访问权限。计数不能泄露被过滤资源；加载失败/未加载不显示为零关联。
- 关联查询可以在抽屉首次打开时获取并使用现有缓存，不为主视图增加常驻大块布局或逐图轮询。
- Host/K8s 快捷打开携带资源参数，顶部查看态再由服务端校验；“全部”依旧解析当前授权范围。
- 本轮仅验证本地原型交互、布局、键盘与可访问性，不运行 Kubernetes、不迁移正式组件或声称正式产品验收通过。

本提案保持 [PlanV2 资源绑定](../01-telemetry-dashboard-and-ai.md) 的已确认职责；正式组件现状见 `web/apps/enterprise/src/components/dashboards/dashboard-binding-summary.tsx` 及 `resource-dashboard-links.tsx`。

## 原型验证

`artifacts/resource-links-ux-20261007/verify-demo.mjs` 使用本地文件模式验证；`verify-final.log`、`proof.json` 和对应截图保留证据。三种桌面尺寸 × 中英 × 明暗共 12 组路径检查，加上无关联、读取失败和只读用户，共 15 项通过。覆盖菜单键盘与焦点恢复、只读反查、资源页管理、逐项预览取消/确认、入口预选、包含未绑定资源的授权范围、标题按钮备选及解除后目录仍保留仪表盘。12 组关联抽屉的 Axe serious/critical 为 0，未定义 token、水平溢出和页面脚本错误检查通过；三份源文件均低于 2,000 行。

可直接在浏览器打开本地 `demo.html`。HTTP 预览助手的后台启动被自动审批拒绝，返回 `blocked by policy`；未创建监听进程，改用本地文件方式完成展示与验证。上述结果只属于讨论原型，不代表正式权限、发布或遥测数据的验收。
