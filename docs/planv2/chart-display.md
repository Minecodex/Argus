# 正式统计图的显示配置

本文件记录 Demo 高级图型选项迁入正式组件后的契约。配置保存在 Panel.display 和既有 unit、decimals、legend、thresholds 中，经个人草稿、样本预览、完整发布差异和不可变 Revision 生效。UI 与 AI 创建使用同一份 OpenAPI 定义和服务端校验。Dashboard 没有新增导出或 AI 分析界面。

## 显示与查询的边界

- 显示计算只处理查询已经返回的样本；不改查询语句、查询模式、时间步长、限制、来源或参数，不影响 query_hash。发布 Spec Hash 和 Revision 正常变化。
- 切换 Metrics 图型保留原查询模式；需要瞬时值或区间统计时由作者在查询配置中明确选择，不能为了画 Stat 自动改成瞬时查询。
- 样本计算独立作用于每条序列，不跨来源、资源或 Target 合并。堆叠只是作者明确启用的显示效果，原始序列仍分别保留。
- AI 工具交付已发布查询的完整结果，显示计算不会替换文件中的结果。分析可以读取已发布显示配置理解图表含义。
- 浏览、样本预览和全屏使用同一套 @argus/ui 渲染组件。样式使用设计 token，Canvas 颜色在主题变化时重新解析。

## 当前支持矩阵

| 图型 | 显示计算 | 最小/最大范围 | 展示阈值 | 其他配置 |
| --- | --- | --- | --- | --- |
| Time series | 保留逐点数据 | 数值轴 | 水平参考线 | 折线/面积/柱形、堆叠、折线平滑、图例、区间缩放 |
| Stat | last/min/max/mean/sum | 不适用 | 数值颜色 | 单位、小数位 |
| Gauge | 同上 | 表盘范围 | 指示颜色 | 单位、小数位 |
| Bar gauge / Bar | 同上 | 数值轴 | 数值颜色和垂直参考线 | Bar gauge 显示背景 |
| Pie | 同上 | 不适用 | 不适用 | 环图、图例；负值无法作为扇区 |
| Histogram | 同一时刻累计桶差分 | 不适用 | 不适用 | 同一标签身份、唯一合法 le 边界、非负且单调的累计桶 |
| Heatmap | 保留逐点数据 | 色阶范围 | 不适用 | 序列 × 时间；不冒充分布桶热图 |
| State timeline | 保留观察到的区间 | 不适用 | 状态颜色 | 缺失样本形成断点，不向查询末端外推状态 |
| Scatter | 保留逐点数据 | 数值轴 | 水平参考线 | 时间 × 样本值、图例、区间缩放 |
| Metrics Table | last/min/max/mean/sum | 不适用 | 不适用 | 按序列显示标签和计算值 |

Logs 的数值聚合图复用适用的显示能力。原始 Logs 表格、Trace 和 APM 保留专用结构与统计口径，不接受不生效的数字显示选项。

## 计算与校验

- 未配置 reducer 时使用 last。最后一个样本缺失就显示缺失，不回填较早的正常值；min/max/mean/sum 忽略缺失样本，全部缺失仍显示缺失。
- mean 是样本算术平均，不按时间加权。sum 是样本求和，不是计数器增量，也不是默认请求总量。编辑器和结果区明确提示口径；请求速率、增量和分位值应在查询中定义。
- min/max 留空表示自动；显式 0 会保存。两者同时填写时必须有限且 min < max。percent_ratio 的范围/阈值仍填原始 0–1 值，格式化时才乘 100。
- 阈值可选，最多 16 项，数值必须有限且严格递增；value >= 阈值时采用最后一个满足条件的 tone，低于首项保持默认颜色，缺失值不着色。tone 只能为 info/success/warning/danger。
- 阈值仅作展示，不触发告警，不成为 AI 诊断必填规则。时序/散点显示参考线，不把整条序列染成最后值的颜色。
- 不支持的 reducer、范围、阈值、堆叠、平滑等由服务端拒绝；柱形时序不能平滑。编辑器切换图型时移除不适用的显示项，查询定义保持原有语义。
- Histogram 拒绝重复/非法边界、不同来源或标签身份、不同样本时刻、缺失及非单调累计桶，不强行拼成有效分布图。

当前矩阵是正式实现范围，不承诺 Grafana 全部变换、字段覆盖、多轴、值映射或任意插件。正式 Collector 到浏览器与 Chat 的整体部署验收仍由 [实施状态](./implementation-status.md) 跟踪，不能用 mock 浏览器或存储集成替代。
