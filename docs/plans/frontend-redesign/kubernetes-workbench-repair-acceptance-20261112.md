## 共享样式与大盘

- 统一仪表盘卡片间隔、内容内边距、底部信息行、表格密度和空态；统计块等宽排列，节点卡片按实际组数占宽，容量显示可读单位。
- 默认受管模板升级到第 3 版：趋势保持两列并增加高度，关系图独占一行；中英标题按当前语言显示，集群标题与状态徽标留出间隔。
- 关系图使用共享 UI 的分层卡片和实际坐标连线，支持滚动、方向箭头、焦点资源和历史资源显式展开；不压缩节点文字，不冒充调用拓扑。服务端 200 节点上限不变。
- 不完整状态与快照时间合并到信息行，避免挤出摘要。面板运行时自行加载共用样式，独立页和嵌入页一致。
- 原生权限不足仍明确提示；没有扩大接入权限、修改正式数据或伪造零值。
