# 主机与列表操作菜单验收

日期：2026-10-13。范围：本轮三项桌面门户调整。

| 位置 | 操作入口 |
| --- | --- |
| 主机详情的 OTLP 收集器卡片 | 右侧「…」提供修改路由、路由测试；路由状态、测试结果和变更预览在弹窗中展示 |
| 主机列表 | 每行一个「…」，包含编辑、组件与采集、接入进度/重试、升级/修复/卸载采集器和卸载主机；已卸载主机提供删除记录 |
| 主机详情 | 删除独立路由卡片、生命周期卡片和右上角卸载按钮 |
| 企业门户其他列表 | Kubernetes、仪表盘与关联仪表盘、告警、组织、模型、MCP、凭据、远程会话/录像复用共享菜单 |
| 平台列表 | 企业管理员、Sandbox 服务连接、镜像、Profile、配额和活动会话的行操作使用共享菜单；启停状态改为只读标签，启停操作进入菜单 |

名称和请求 ID 保留直接打开详情的入口。新增、搜索、筛选、刷新、批量操作及确认区的按钮保持各自职责。菜单来自 `@argus/ui` 的 `ActionMenu`，共用语言、主题、键盘、禁用和危险操作样式。

主机采集器生命周期在选择时重新读取当前实例、Claims、路由、发行版本和资源版本；详情与列表共用有效 Profile 提取逻辑，排除其他实例、释放、过期或无 Profile 的 Claim。菜单展开和路由测试不生成执行；变更继续通过原 PendingAction 预览、确认、审批及审计。路由和采集配置预览失败保留可见错误，确认后刷新遥测查询缓存。

## 验证

- 90 个不同 Playwright 场景的最后执行结果全部通过：中英 × 明暗菜单与键盘/危险样式、三种桌面宽度、主机/堡垒机卸载、未完成接入删除、路由测试与取消预览、采集卡片、Kubernetes 安装、设置治理、平台启停和配额、MCP 编辑及选择持久化、会话录像列表。分轮去重结果见[验证汇总](../../../artifacts/row-actions-20261013/verification.json)。
- 37 项现有主机接入、名称校验及 PendingAction 确认单元测试通过；企业与平台 TypeScript、相关源码/测试 ESLint、国际化和 design token 检查通过。
- Enterprise、Platform 和 Template Runtime 的 real 构建通过，产物检查无 Mock 种子或占位 API 地址。
- 浏览器使用显式 mock 模式和独立端口/context。活动远程会话 Mock API 明确不可用，远程会话目录的菜单浏览器验收使用已有录像数据；未将其记为真实活动会话的执行验收。
- 本轮未发布到 `argus.dev`，也未执行真实主机的升级、修复、路由变更或卸载。

证据目录：[本轮验证与截图](../../../artifacts/row-actions-20261013/)。按执行顺序检查 `final-browser.log`、`final-regressions.log`、`verified-regressions.log`、`verified-final.log` 和 `platform-final.log`；汇总采用每个场景的最后一次结果，保留修正前的失败证据。最终 real 构建记录为 `build-real-verified.log`。
