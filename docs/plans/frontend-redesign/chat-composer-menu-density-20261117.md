## 共享实现

两处共用 `@argus/ui/ComposerActions`。原来都使用440px文档浮层宽度，改为独立design tokens：普通菜单260px，含说明的菜单320px。选项文字从HeroUI默认14px统一为系统正文13px，辅助说明12px；图标和选中标记统一16px，选中标记预留位置。

菜单内边距和分区标题收紧，选项垂直/水平内边距6px/8px，采用与系统控件一致的圆角和较轻阴影。说明完整换行，使用现有HeroUI v3 Dropdown管理定位、焦点、键盘和外部点击。业务入口、模式切换、权限更新和审批策略保持原逻辑。

官方组件参考：[HeroUI v3 Dropdown](https://heroui.com/docs/react/components/dropdown)。实现只新增共享样式类和尺寸token，未增加业务组件库。
