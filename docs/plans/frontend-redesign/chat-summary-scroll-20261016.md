# 会话置顶摘要与统一滚动

## 本轮要求

- 会话右上角增加“置顶摘要”，在锚定浮层内展示原有 MCP 连接与会话文件，移除原来的头部常驻区域。保留授权、运行期间禁用、文件预览/下载和 Workspace 删除确认；摘要内容多时允许纵向滚动。
- 消息中的结果完整展开，不使用内部纵向滚轮。列表分页和折叠详情仍保留；宽表可以横向滚动。正文与输入区宽度不变。
- 企业、平台、模板和弹层滚动条共用聊天原有尺寸：9px 轨道、2px 透明内边，颜色随主题变化。

## 实现边界

`@argus/ui` 提供通用 ContentPopover，使用现有 HeroUI/React Aria 的锚定定位、Escape、外部点击和焦点恢复。业务 MCP 与文件继续由 ConversationWorkspace 读取和管理，切换会话重置浮层。

共享模板上下文新增可选 `layout`（`document | preview`），没有该字段时保持预览模式。宿主校验 resize 是有限、正数且向上取整后为安全整数，不再静默截断为 2000px。Runtime 依照内容实测高度通知宿主，文档样式去除代码、日志、表格和仪表盘的纵向高度上限；仪表盘网格行以原配置为最小高度，内容增高时网格随之增长，避免面板重叠。

历史模板仍校验原 Hash，文档布局来自共享 Runtime，不更新旧源码。根节点使用 flow-root，将子元素外边距纳入高度测量，修复 11px 溢出。工具绑定、只读接口、权限、冻结结果、分页与确认边界均不变。页面级滚动条实现收敛到共享样式和 design tokens，移除终端标签页的独立尺寸；Xterm 自绘滚动条同步采用相同尺寸。统计值将单位作为次要字号展示，长单位可换行，避免相邻列重叠。
