- 标签间距 4px，字段与卡片间距 12px，操作组 8px，卡片内边距 16px，页面与分区 24px。

## 同集群验收的依赖边界

Docker Desktop 已有正式 Argus 与 Judex，Strimzi 固定全局 RBAC 名称会阻止第二个 Helm 安装。安装器按锁定的 Strimzi 1.1.0 图表检查完整的角色规则和 CRD schema；仅在完整且兼容时复用全局定义，临时 operator 的绑定使用独立 release 名称，仍只监听自己的 Namespace。Altinity 同样检查既有 CRD 后关闭 CRD 更新 hook，并使用 Namespace 级 RBAC 和明确的监听范围。共享 CRD 不重标所有权，测试卸载不删除它们。缺失、混合所有者或不兼容定义仍阻止安装。

OpenSandbox 复用现有安装配置中明确锁定的 controller digest；E2E 增加 `--shared-controller-config`，仍校验 CRD、Pod 和镜像身份，不改变外部 controller。此调整用于同一个 Docker Desktop 集群中的临时验收，不改变业务权限与执行架构。

PKI trust-source 的 Role/RoleBinding 使用 release 名称隔离，仍只访问本 release 的 trust-source ConfigMap。暂停后的恢复先还原所有副本数再等待健康，避免应用等待尚未启动的 PostgreSQL/Redis。Docker Desktop 本地验收的无地址 LoadBalancer 仅在 Namespace/Helm 所有权、UID、ResourceVersion、无外部地址且唯一相关 finalizer 均符合时清理；有分配地址或外部来源的 Service 不适用此例外。

隔离的本地转发模式将已建立的 Gateway 拨号地址显式传给安装验证器；验证安装 CA、Connector 主机名、TLS 1.3 与 HTTP/2，报告为 `connector-forward-tls`，并记录 `EXTERNAL_CONNECTOR_LB_NOT_EVALUATED_LOCAL_FORWARD`。默认 `connector-lb` 检查和 Production 要求不变，不把本地转发算作外部 LoadBalancer 已验收。
