# 会话文件目录树

## 展示与交互

右上角“置顶摘要”中的“会话文件”改为按文件真实 `path` 分层的目录树。`/workspace` 根目录默认展开，子目录默认收起，可以鼠标点击或键盘 Tab、Enter／Space 逐层开合。同一目录中先显示子目录，再按当前语言和数字自然顺序排列文件；不同路径下的同名文件分别展示。

文件使用统一紧凑行：图标、单行文件名、文件大小、下载图标。点击文件名打开现有只读预览；下载仍使用原始文件 ID 与授权接口。长文件名省略显示，悬停可查看完整路径和类型信息。目录树沿用摘要浮层的纵向滚动，避免横向撑开；中英文和明暗主题复用现有语言配置与 design tokens。

会话文件区只提供目录浏览、预览和下载，不提供独立“删除 Workspace”入口、确认弹窗或删除请求。中英文保留说明统一为文件随会话保留，永久删除会话时一并清理。相关删除状态轮询与已失效的操作文案一并移除。

远程输出新规则为 `results/<业务相对路径>`，AI 可以在输出目录内按业务创建子目录。执行／步骤／资源等 UUID 集中到 `results/meta.json`，不再生成 UUID 目录；重名结果用可读数字后缀保留。旧 `remote/results/<request-id>/<step-id>` 结构仅保留已有历史文件，详见[结果目录与元数据](../../plan7/19-workspace-results-and-metadata.md)。目录树按服务端实际返回路径展示。

## 实现边界

通用 `FileTree`、`FileRow` 和样式位于 `@argus/ui`。`ConversationWorkspace` 负责查询和组合，`ConversationFile` 继续负责授权下载地址、预览请求、错误和弹层。消息正文附件保留原有卡片表示。

目录由现有 `workspace.listFiles` 返回的文件元数据派生，不增加磁盘扫描或修改存储、API 和权限边界；没有文件的空目录不在本次接口返回范围内。缺少路径的文件保留在根目录；异常父路径不生成跨根层级。首次使用且尚未创建 Workspace 时显示空列表，文件服务故障明确显示不可用，不能显示为“没有文件”。本次移除文件区的独立删除能力；会话永久删除和后台授权清理的存储生命周期保持既有边界。

## 验证
