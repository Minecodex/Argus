# 应用环境筛选与统一分页

2026-10-27，根据企业门户截图调整应用目录、管理页顶栏和各列表分页。

## 产品行为

- 应用目录使用共享 `FilterBar`：名称或标识搜索与环境下拉相邻。环境提供全部、生产、测试、预发布、开发，与新建应用一致；两个条件取交集，任意条件变化回到第一页。无匹配时提示调整条件。
- 管理门户共享顶栏移除固定的“系统正常”标识，不再无依据地宣告全系统健康；页面本身的实际监控状态与错误提示保持原有职责。
- 列表分页统一由 `@argus/ui` 的 `Pagination` 渲染，位于列表下方右侧。使用 28px 紧凑箭头、数字页码、当前页高亮及长页数省略号；支持键盘焦点、双语可访问名称和明暗主题。
- 已知总页数时显示当前页和总页数；游标接口没有总数时，仅显示当前页和已取得游标可访问的页码，不把当前页数量当作全集。已知总数但尚未取得游标的远端页码禁用。请求中、首尾页和空结果正确禁用翻页。
- 统一范围包括应用、服务、接入端点和密钥、监控、Kubernetes 工作台与操作记录、告警及其配置列表、企业审计、授权目录、资源选择弹窗、查询结果和工具结果视图。平台中复用的共享控件自动采用相同规范；没有分页的列表不额外制造分页。
- 授权双列表各自保存页码，避免翻动左侧时把右侧较短列表带到空页。流程向导的“下一步”不属于列表分页。

## 查询契约与边界

`GET /applications` 和 `application.list` 工具增加可选 `environment`，精确匹配应用环境；省略表示不限制环境。沿用应用环境标识校验和显式资源授权，在 SQL 的 `LIMIT` 之前同时执行授权、名称/标识、状态和环境条件。

环境进入签名游标的筛选绑定，跨环境复用旧游标被拒绝。OpenAPI、生成的 Go/TypeScript 契约、HTTP 入口、领域查询、SQL、真实客户端和独立 Mock 已同步。不修改应用归属、创建确认流程或数据库 Schema。

## 后续：筛选栏容器与日期布局统一

同日根据告警历史和监控列表截图，告警所有列表筛选接入共享 `FilterBar`，包含当前告警、历史、通知记录、策略、屏蔽/抑制与通知渠道/路由。历史的开始日期和结束日期移到同一筛选栏，搜索、下拉、日期输入和右侧导出按钮底边对齐，桌面有空间时不再另起一行。

共享筛选栏增加日期范围与右侧操作槽，尺寸使用设计 token。搜索保持紧凑、按剩余空间伸缩；下拉按内容占宽并设统一上限，两个日期控件保持在一起。应用沿用共享容器；仪表盘删除透明背景、无边框、无内边距的局部覆盖；监控集成目录的搜索也使用同一组件。浅色采用统一白色 surface，深色跟随主题色，不写死白色。

日期筛选的 `from`/`to`、北京时间日界限、URL 状态和清空行为保持原有契约，筛选仍会重置分页；本轮没有修改 API 或数据权限。

验证记录：新增 `shared-filter-bars.spec.ts` 的中英 × 明暗 × 1280/1440/1920 共 12 项通过，逐页比较背景、边框、圆角、内边距、搜索高度和字体，验证历史日期不换行、查询参数和可访问性。最终截图位于 `artifacts/shared-filter-bars-final-20261027/`；其中布局数据仅为独立 Mock 浏览器数据。本次仍未部署到本地服务。

既有回归暴露长分组名的隐藏宽度测量文本换行问题，已在共享 Select 修正为单行测量与有界溢出，不再撑高控件。应用分页、监控筛选和告警流程 29 项通过；修复后仪表盘 12 项与共享布局 12 项同轮复验通过，本轮合计 53 个不同 E2E 场景有通过证据。共享 UI 相关 27 项单元、类型检查、国际化、样式和 ESLint 通过；最终 real 生产构建通过，记录在 `artifacts/shared-filter-bars-build-20261027.log`。

## 2026-10-28：分页与容器边缘的留白
