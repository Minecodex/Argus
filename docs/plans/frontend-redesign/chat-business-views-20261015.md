# 会话业务视图与管理门户统一

## 已确认范围

用户确认上一轮工具展示分类，并要求各视图尽量沿用管理门户的体验。仪表盘草稿明确为**只读布局与配置，修改继续交给 AI**。本轮不增加模板写入、任意 URL、任意工具执行或业务提交通道。

## 实现

| 范围 | 本轮行为 |
| --- | --- |
| 106 个工具绑定 | 38 个业务查询、52 个共享变更预览、13 个紧凑步骤、1 个操作状态入口、2 个文件入口；共有 90 个模板绑定、25 个入口、26 份当前源码 Hash |
| 辅助调用 | 工具检索/详情/调用、目录/条件解析、草稿创建/保存/校验、取消/恢复使用摘要和通用详情；校验问题提供路径、级别及原因表格 |
| 操作视图 | 服务器将可信 `display.action_ref` 与调用一起持久化；同一会话按 ActionRef 合并预览、确认和状态查询。模板详情按需展开，确认/取消仍由已有宿主控制 |
| 查询去重 | 服务器发布绑定 Query/Attempt 的 `result_key`，同一结果的重复读取保留调用记录并复用结果视图；不同 Attempt/新查询继续保留独立卡片 |
| 列表 | 使用共享 DataTable、FilterBar、StatusBadge、Button、分页；资源名称可打开行详情，字段由模板提供。主机/集群列与后台目录对齐，缺失统计不补造 |
| 详情 | 使用管理门户 KeyValueGrid，结构化对象按字段展开；简短事实数组（例如静默原因）保持可见 |
| 草稿/定义 | 使用管理门户共用的 DashboardGrid、DashboardPanelHeader 与 Tabs；按冻结布局展示面板，右侧检查查询、显示和范围配置；无查询目标明确空态，定义不制造查询曲线 |
| 图表/日志/调用链 | 沿用已有共享 ObservationPanel 和冻结查询结果；附属表格、字段与分页同步使用共享视图 |
| 样式构建 | Template Runtime 启用与门户一致的 Tailwind Vite 插件，预打包 HeroUI 与共享样式，消除未编译 `@apply` 导致的标签页/控件样式差异 |

新增共享视图在 `@argus/ui`；Runtime 提供通用渲染适配器，不按工具名称选择业务字段。模板源码继续负责业务字段、布局和交互编排，历史源码按原 Hash 保存。共享依赖在安装禁止网络的 CSP 前加载完成。

## 封存结果筛选契约

`result.page` 增加可选 `search`、`filters`、`sort`、`direction`，在整个当次封存集合上处理，再按有界页返回。只开放根 `items/page.items`，不允许在样本分片或冻结面板目标选择器上附加过滤。

- `search` 为长度受限的普通文本，不是表达式；不会搜索凭据或控制令牌字段。
- 精确过滤字段为 `status/connection_status/severity/level/environment/namespace/resource_type/service_name/signal/type`；排序字段另有固定白名单。
- 游标继续绑定主体、授权版本、展示、封存版本、集合/分片，并增加规范化搜索、过滤和排序条件。换条件不能复用旧游标。
- 返回 `total`（匹配条数）、`source_total`（本次封存条数）、`facets`、`offset` 与 `complete`。高基数字段不生成截断下拉列表，仍可文本搜索。
- 字段条件只筛本次结果；新资源、时间和业务查询由 AI 发起新调用。没有匹配时写明“本次结果无匹配”，不宣称系统中没有该资源。
- 原请求条件单独只读展示，不把用户在卡片内的筛选当作原查询参数。冻结仪表盘仍展示实际执行参数。

只读接口每次执行原有会话所有者、工具权限与资源 Scope 校验。OpenAPI 和生成的 Go/TypeScript 类型已更新；后端在规范化参数后继续执行严格白名单校验。

## 调用摘要

原生 Gateway 产生可选 `display` 元数据，与 `tool_call_result` 一起写入 Ledger，并经同一 SSE 转发：`mode`、公开 `facts`、校验 `issues`，以及必要的 `action_ref/result_key`。门户只负责翻译通用标签、布局和关联，不从任意 ID 猜资源名称，也不把元数据变成提交授权。

此元数据不进入模型业务结果，不改变完整结果 Artifact、发现协议或工具权限。没有新元数据的历史调用仍使用原有显示；旧展示 Hash 不替换成新源码。
