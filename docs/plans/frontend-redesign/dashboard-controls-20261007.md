# 仪表盘查看条件、默认设置与自定义过滤项

日期：2026-10-07。状态：本轮交互、候选同步、源码与所选真实配置/发布闭环已完成，正式 `portal-20261007-r6` 已部署并复核通过。

用户截图指出查看页的时间、资源与刷新距离过远，变量编辑器混合固定时间设置，条件、候选、删除和新增按钮堆在一起。本轮采用紧凑的查看条件工具栏、独立默认设置、左列表右配置的过滤项编辑器。沿用唯一共享组件库及现有查询、权限、草稿和发布流程。

## 官方参考与采用的交互

[Grafana Use dashboards](https://grafana.com/docs/grafana/latest/visualizations/dashboards/use-dashboards/) 将当前时间范围、时间选择器、刷新和自动刷新作为固定仪表盘控件；支持相对与绝对区间。[Variables](https://grafana.com/docs/grafana/latest/visualizations/dashboards/variables/) 将自定义变量作为作者配置、查看者选择的独立内容。本轮借鉴这些任务划分，继续使用 Argus 的统一样式和查询能力，不引入额外的 Grafana 查询语法或权限模型。

- 查看页：时间区间按钮、资源下拉、自定义过滤下拉、刷新和间隔相邻排列，均为 32px；条件较多时紧凑换行，不使用 `space-between` 拉满整行。
- 区间选择：点击按钮在就近弹层中选择相对或绝对范围，明确应用/取消，保留日期字符串和时区契约。
- 默认设置：独立“仪表盘设置”配置默认时间和默认刷新间隔，进入个人草稿，统一预览发布。查看时的临时时间/间隔不会写回 Revision。
- 自定义过滤：左侧列出过滤项，右侧只编辑一项；基本身份、候选查询、默认选择、预览和引用分别组织。候选条件/依赖及来源映射按需展开。预览候选、删除及添加分属各自任务区，不堆在表单底部。
- 候选预览使用确切的默认时间，包括绝对区间；条件变化取消旧请求，迟到结果不能覆盖新定义。分页和失败不能作为值消失的证明，沿用共享选择器的成员校验规则。

## 资源范围的配置与执行逻辑

| 范围 | 配置位置 | 作用 |
| --- | --- | --- |
| 用户可访问的资源 | 组织与权限 → 数据授权，现有显式 Host/Cluster 对象授权 | 服务端访问上限，用户/部门/角色等授权关系由既有权限体系解释 |
| 本次查看选择 | 顶部“资源范围”下拉 | 提交 `resource_ids`；只能缩小授权范围，不能授予权限 |
| 默认资源行为 | 当前没有发布配置中的资源名单；未指定资源即“全部” | 解析当前授权且 active 的 Host/Cluster，再按统计图适用类型及来源匹配 |
| 快捷入口 | Host/K8s 页面绑定仪表盘 | 打开时传入资源参数，预选该主机/集群；不决定查询全集 |
| 自定义过滤 | 管理过滤项，并在统计图查询中明确引用 | 只作用于引用者及其依赖，不替代系统资源范围 |
| 图内局部条件 | 该图的局部过滤 | 叠加顶部时间、系统资源和来源约束，不扩大范围 |

前端 `DashboardControls` 展示当前选择；`useDashboardExecution` 持有查看态，初次进入使用发布默认时间/变量及入口资源，重新加载回到这些初始条件。没有新增跨用户共享或持久化的查看资源偏好。

后端 `internal/dashboard/runtime_scope.go:resolveResources` 根据当前 Actor 获取 Host/Cluster 授权 ID 并过滤 active 状态；显式选择任何未授权或已失效的资源返回拒绝，不能静默把失败选择替换为全部。`resolveSources` 再按来源类型、信号及能力版本匹配；各 Panel 的适用资源类型继续有效。`resource_ids=[]` 表示使用当前授权范围，与“没有授权资源”的解析结果为空是两回事。

“全部”提交空的资源选择，不能把当前候选页的 ID 当作授权全集。候选目录晚于弹层打开返回时，静态目录直接从当前 props 渲染；远程分页候选仍由请求代次和成员校验管理。已选择但当前候选暂未包含的 ID 保留显示，最终执行必须重新通过服务端授权。

因此，目前用户不需要在变量编辑器设置主机范围；作者也没有通过资源绑定限制所有查看者查询全集。若后续需要作者固定可查询资源集合或保存个人常用范围，需要单独确认其语义和存储契约，本轮未新增这两种行为。
