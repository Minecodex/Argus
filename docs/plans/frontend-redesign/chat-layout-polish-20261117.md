## 工具活动

- 输入、输出和命令文本使用主题中的 `--bg-muted`、`--text-primary`、边框及字体 token，浅色与深色切换即时生效。
- 共享 `ToolActivityRow` 将耗时、状态、展开箭头收敛到独立尾部区域。缺少摘要或耗时时仍保留耗时列，数值右对齐，文件增删行统计不改变对齐。
- 业务视图点击后在会话内使用宽结果列，最大沿用 `--chat-result-width`，受桌面可用空间约束；工具标题行保留阅读列位置，参数文本和普通回复继续保持阅读宽度。收起后恢复原布局，不移动工具事件。
- 宽度由共享活动组件显式的 `data-wide` 状态驱动；折叠活动时清除可见宽布局，业务视图继续按需加载。

## 置顶摘要

- 每次打开摘要，MCP、文件、资源三个分区均默认收起；空资源也保留第三个分区及数量。
- 引用资源使用共享分类 Select、名称 SearchInput、DataTable、Pagination。仅在当前已加载的会话引用中筛选，不查询其他资源目录。分类与搜索可叠加，改变筛选后回到第一页，每页五条，资源变更后页码限制在有效范围。
- 名称、链接和不可访问状态继续由原有授权解析 hook 决定；读取中或权限变更时不使用旧缓存名称，不展示技术 UUID 代替业务名称。
- 关闭后重新打开摘要会重置展开及筛选状态；MCP 的已保存选择、文件本身和会话数据保留。

## 模型入口

- 会话头部移除模型选择，输入框底部发送按钮左侧放置紧凑模型选择，向上展开；新会话和已有会话均可选择，切换不清空草稿。
- 可选模型、不可用原因、已保存模型仍来自现有 API。已有会话使用原 `updateModel`，新会话记住草稿选择并用于创建。保存期间防止重复选择和发送，失败显示可读错误，成功后更新本地最近模型偏好。
- 共享 Select 新增可选 pill 外观与弹出方向，默认外观、方向不变；业务页面仅决定布局，控件圆角、配色和字号归共享 UI。
- 后续反馈将模型按钮的 pill 底色改为透明；正文、工具输入输出及弹出的选项列表继续使用原主题配色。
- 模型按钮再调整为按当前所选名称自适应宽度，箭头与名称使用紧凑间距；长名称保持最大宽度和省略显示，不按其他模型选项的最长文字预留空间。共享 Select 新增可选 `sizing="selection"`，原字段及最长选项 sizing 行为不变。
