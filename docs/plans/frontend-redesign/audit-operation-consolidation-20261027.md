# 企业审计与操作进度收敛

## 已确认范围

取消企业门户“任务记录”页面、路由和菜单。保留 PendingAction、审批、Execution、运行队列、幂等与结果对账机制。企业审计是统一的历史追溯入口；会话在原工具位置显示结果，资源详情承接进度与一次性命令领取。

## 数据与权限边界

- 原始审计事件与 Hash 不修改；事件结果描述该阶段是否成功，不能代替最终执行结果。
- 审计公开对象增加独立的 `operation` 当前状态投影，包括稳定动作类型、操作关联、执行状态、错误码、资源名称和时间。不返回私有计划、Token、命令或凭据。
- 预览、确认、审批、领域提交、执行终态和结果领取沿用同一 `action_ref`。终态与审计事件在同一数据库事务提交；条件更新阻止重复执行产生重复终态事件。
- 审计关联查询使用精确 `operation_ref`，继续执行企业域、资源范围、分页和签名游标校验；关联条件参与游标签名。无关联的历史事件保持原样，不凭相似时间或资源猜测。
- 结果领取继续要求原发起人、当前授权版本、有效期和单次原子消费。审计权限不能授予结果领取或执行权限。
- `GET /enterprise/executions` 保留为运行状态读取能力，支持 `action_ref` 和 `resource_id` 筛选。会话和资源页面使用实际执行状态，不伪造进度百分比。

## 展示

- 企业审计列表分别展示事件结果与执行结果；动作名称打开详情，技术 ID、Hash 和原始事实收进技术信息。
- 操作详情呈现资源名称、当前状态、时间与关联事件时间线；时间线分页读取并在执行过程中更新。
- 已知审计动作、资源类型共享双语目录，包含遥测隧道、控制隧道、监控采集、应用、远程执行与 Kubernetes 操作。未知代码显示本地化通用名称，原代码留在技术详情。
- `@argus/ui` 的 OperationPanel 统一状态、阶段时间线、说明和动作布局。业务页面只提供数据和本地化文案，保持设计 token、桌面布局和深浅主题一致。
- 主机、集群详情提供“操作进度与结果”；安装命令显示执行指引、有效期、复制入口与可展开校验信息。命令仅驻留当前组件内存，关闭或离开页面即清除。
