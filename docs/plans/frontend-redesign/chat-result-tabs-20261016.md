# 工具卡片的视图、返回内容与查询参数切换

展开工具卡片后，顶部显示“视图 / 返回内容 / 查询参数”三个标签，默认进入视图。直接展示该 ToolCall 已记录的公开返回内容和实际输入参数，不重新执行工具或查询。没有相应记录时明确显示空态；`null`、`false`、`0`、空对象和空数组仍按实际值展示。

标签切换由共享 `@argus/ui` 的 ToolResultDisclosure 和 Tabs 负责。切换时保持视图挂载，只隐藏非活动面板，因此 iframe、筛选、分页和展开状态继续保留；收起整张卡片时销毁 Runtime，重新打开默认返回视图。没有模板的辅助调用仍沿用紧凑步骤；确认控件保持在宿主原有位置。

返回内容与参数沿用既有公开调用投影、脱敏和展示大小上限，完整业务数据仍在原视图或交付文件内。新增切换不会扩大只读接口权限、改写历史 Hash 或添加工具调用。公开消息投影和 Mock 保留已有可选 input/output 字段，与 Ledger 回放得到的 ToolCallTrace 对齐。
