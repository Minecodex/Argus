## Q11 的取舍依据

1. 受限 shell 语法可以确定性映射操作，但维护全部 Linux 命令规则不属于本期目标。
2. 任意 Python 可以直接写文件、调用网络 API、动态导入或运行子进程；递归解析 Python 和 shell 不能普遍给出完整副作用清单。
3. 按完整脚本授权是可实现的执行契约。批准的是本次固定内容和执行上下文，不是「脚本已被证明没有风险」。
4. 新方案保留平台业务工具，并新增 connect；不将所有平台操作迁移成 shell，也不将 Workspace 变成生产执行通道。
5. 真实模型是否优先本地分析、是否提出必要且有界的远程取证，必须单独验证；工具描述或固定 Replay 不能替代这项证据。
