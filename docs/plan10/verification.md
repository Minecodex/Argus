## 验证边界

- 原型只在内存中记录生成语句与构造配置的精确对应；未实现生产解析器、语义等价转换或完整 PromQL/KQL/GraphQL。
- 指标为确定性数值样例；日志/链路是有限记录。构造器对这些样例执行选择、过滤、聚合与计数，不代表真实后端查询完成。示例资源使用独立 ID 选择并按声明的样例关系映射序列；资源范围不再拼入 Builder 语句。正式请求必须使用可信 ResourceRef/来源身份。
- 未验证真实 Catalog 分页、实时采集、网络错误、预算、跨租户权限、执行中撤权或真实模型。
- 没有查询保存、历史、分享、查询组持久化或仪表盘发布流程。
- 不属于正式 enterprise 门户、Collector/Kubernetes 全链路验收或上线；正式验收要求见 [设计方案](./README.md#9-实施顺序与验收)。
